# GP 遗传编程挖掘

算法目录注册 `gp`，与 RD-Agent、统计挖掘共用 `/alpha-agent/preview`、
`/alpha-agent/evolve`、持久化任务队列和资源租约。CPU 控制器复用
`statistical_runtime.py`：冻结行情与元数据 → 父进程封存 SHA-256 →
受限子进程搜索 → 因子定义和结果在同一事务保存。取消、重启恢复、幂等及
用户隔离沿用原链路；历史 `statistical_*` 产物名保持兼容。

GP 在 A 股日线 OHLCV/成交额上演化白名单 DSL 树，采用锦标赛选择、精英保留、
子树交叉与变异，约束节点数、深度和回看窗口。无需 LLM、GPU 或新增依赖。
评分为 `abs(mean RankIC) × 三段方向一致率 − 复杂度惩罚 × 算子数`，
按逐日截面秩相关去重后保留 Top-K。RankIC 标签是股票内向后 horizon 根
收盘收益；统计口径复用 `statistical/ic_stats.py`，ICIR 为非年化 RankICIR。

挖掘结束以后的行在建立标签和适应度前物理剔除。可选 OOS 只对已选定公式
出具报告，不参与搜索或排序。搜索内 IC 有选择偏差，不能当成独立验证成绩。
本模式不会自动将结果认定为高质量因子或自动生成训练数据。

`GPConfig` 是预览、任务快照、执行的统一参数约束。默认 48 个体、8 代、
Top-5、seed=42；种群×代数≤2048、输入≤200万行、树≤63节点、回看≤250根。
大区间应先缩小股票池试跑。结果保存随机种子、参数、每代最优记录、实际
评估公式数、复杂度、IC/RankIC 及 OOS 证据。

公式转成 Qlib 表达式供展示，回测/生成数据时仍按冻结的白名单 DSL 和候选
哈希核验并计算；不执行任意 Python 公式。通过已有因子列表进入后续验证。
