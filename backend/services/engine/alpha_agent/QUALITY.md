# 统一因子质量入库检查

新任务：`quality_config` → preview/evolve/方向批量入口 → 不可变任务规格 →
算法提出候选 → `quality_gate.evaluate_values` → 同批 BH-FDR → 合格定义入库。
统计/GP 的数值计算沿用受控 worker；RD 复用现有公共面板与 Docker 数值沙箱。
`quality_runtime` 负责适配；`quality_gate` 只负责配置、统计与判定。
参数、逐项证据和拒因保存在既有任务结果 JSON；通过的证据保存到因子 metadata。
不新增表，不将未通过候选写入 `rd_agent_factors`。

| 推荐初始值 | 默认 |
| --- | --- |
| 样本内/外最少有效 IC 日 | 252 / 126 |
| 每日最少股票数 | 30 |
| 样本内外有限因子值覆盖率 | ≥80% |
| 方向调整后的日度 Spearman RankIC 均值 | ≥0.02，样本内外均要求 |
| 非年化 ICIR = 日度 RankIC 均值 / 样本标准差 | ≥0.3，样本内外均要求 |
| 样本外 HAC t | ≥3 |
| 样本外同批 BH-FDR | q≤0.10 |
| 时间四等分后与固定方向同号的段比例 | ≥75%，样本内外均要求 |
| 样本外 RankIC / 样本内 RankIC（固定方向） | ≥50% |
| 样本外不重叠 h 日持有期数 | ≥20 |

所有阈值可在挖掘输入的“统一因子质量标准”调整；不可关闭检查。
这是一套研究入库的工程初始值，不是普适的收益保证。
显著性参考 Harvey 等对多重检验提高证据门槛的研究：
[What Threshold Should be Applied to Tests of Factor Models?](https://www.nber.org/papers/w34898)。
论文的因子模型 t 阈值不能直接证明本系统 IC t 的充分性；此处取 3 是保守起点。

## 计算契约与边界

- Y 与 `label_contract` 相同，h 使用任务预测周期。IS/OOS 各自裁价格窗口后建标签，
  最后 h 个交易日不借用下一窗口价格。
- 使用原始因子数值的日度截面 Spearman，而非算法搜索分或历史聚合字段。
  非有限值剔除；每日样本不足不计 IC；覆盖率分母为本窗口能生成有限标签的价格记录。
  统计搜索的行业中性化及可交易性过滤仍是搜索配置，共同入库口径独立评估原始数值。
- 使用 mining 区间确定方向，OOS 不允许按绝对值重新选方向。反向因子保存 direction=-1，
  单个/批量回测、验证快照继承，组合按方向调整后选高分股票；原始定义和原始证据保留。
- HAC 带宽为 max(自动带宽,h-1)，避免长周期标签只按日频独立样本估计。
  持有期数是有效 IC 日每 h 日取一次的数量下界，不宣称各期统计独立。
- 每批冻结的候选一起做样本外 BH-FDR，计算失败者按 p=1 保留在分母中。
  此校正不覆盖用户跨任务反复试验，也不覆盖根据同一 OOS 调阈值的选择偏差。
- 统计算法旧的 FDR/OOS 质量判定不再提前淘汰新任务候选；它先在 IS 排名、去重，
  然后与 GP/RD 共用统一检查。旧任务保留旧快照、旧行为。
- RD 的搜索训练/验证/测试段全部处于 mining 区间。任务 HDF 独立裁剪，不修改共享缓存；
  holdout 数值只在搜索结束后供固定公式验收，不向搜索反馈。
- 未通过、样本不足、计算失败均不入库。所有候选被拒仍是正常完成的研究任务，
  结果会显示 0 入库及具体拒因；系统执行失败另报任务失败。
- 质量阈值不是交易策略验收。这里不以多头组合 Sharpe/收益直接给因子准入，
  防止把市场上涨当作因子效果；扣费、交易约束、容量及增量价值继续在后续研究中评估。

历史结果与因子不回写，不删除存量记录；新请求必须提供明确的 mining 与后置 OOS 日期。
